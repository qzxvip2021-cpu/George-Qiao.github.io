01 / Evidence map

Evidence Overview

This page presents four evidence classes without treating them as interchangeable. The data cards report approved values exactly as supplied; they do not create a measured curve, a reconstructed event timeline, or a validated simulation-to-flight comparison.

Video-confirmed instrument readout

Displayed summary

Confirms what the AltimeterTwo display showed in the original video, not measurement accuracy.

Saved simulation result

Model snapshot

Records a saved OpenRocket output, not a verified preflight prediction or an as-flown match.

User-reported configuration

Flight setup account

Preserves reported motor, delay, parachute, and JLCR details without claiming original setup evidence.

Unverified or unavailable evidence

Open questions

Keeps accuracy, event identification, launch linkage, and recovery timing unresolved.

05 / Boundaries

Evidence Limitations

Video-confirmed instrument readout

What the display showed

Supports the ten displayed values. It does not independently establish sensor accuracy, physical event identity, or launch linkage.

Saved simulation result

What the model saved

Supports the two named snapshot results, masses, and 14 s delays. It does not identify the verified preflight model or reproduce the as-flown configuration.

User-reported configuration

What was reported

Supports the H219T-14A adjusted to 10 seconds, 30-inch parachute, and no-JLCR account. Original setup evidence is not presented here.

Unverified or unavailable evidence

What remains unresolved

Measurement accuracy, event classification, negative event timing, recovery timeline, verified preflight version, and continuous measured flight data remain unverified or unavailable.
